# 3d-quiz-game

An educational 3D maze game in the browser for German-speaking children from Kindergarten to 4. Klasse (about 4–10 years).
Children explore comic-style mazes and small activities (memory, side scroller, a question
path) and solve math, German and general-knowledge challenges to earn rewards for their avatar.

**Status:** v1 feature-complete and growing: two worlds, three activities, about 70 challenge types matched to the Lower Saxony curriculum (Kita to grade 4), German voice for everything, star jar rewards, animal friends, parents area, installable offline PWA.

Play: https://patst.github.io/3d-quiz-game/

```bash
npm ci && npm run dev
```
